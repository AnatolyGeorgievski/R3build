1. Распаковываете архив с установочными файлами
2. Форматируете 2 сд карты в FAT32 и копируете на них файлы из архива
3. На второй карте удаляем файл `aml_sdc_burn.ini`
4. Вставляем первую карту (используя OTG переходник: micro usb - usb A), 
рестартуем по питанию и ждем когда загорится зеленый светодиод
5. Вынимаем первую карту и вставляем вторую и перезапускаем опять, ждем примерно 2 минуты
6. Вынимаем вторую SD карту и перегружаем последний раз, прошивка  установлена.
