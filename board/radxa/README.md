# board/radxa — референс стендов

Модели в работе: **ROCK 5C**, **2F**, **3B**.

Старт: вендорная загрузка одноплатника → сеть / отладка → при необходимости свой `/init` (net_init), netd, mcp в ramdisk или rootfs. Свой SoC не обязателен на первом шаге.

Слоты моделей: `5c/`, `2f/`, `3b/` — заводим, когда есть dts, conf или скрипт образа.
