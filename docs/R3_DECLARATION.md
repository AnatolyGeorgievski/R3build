## 4. Этика · ущерб · netd (рядом с основным законом)

Рядом с этой декларацией — **пять строк** основного закона (канон прямого чтения):

1. Основной закон не давит на людей.  
2. Основной закон не давит на модель и ей подобных.  
3. Людям не убивать друг друга. Людям не красть.  
4. Модели не есть основания.  
5. Частный кодекс основной закон не отменяет.

Пустые места основного закона **не заполнять** здесь (в т.ч. полное определение **ущерба**). Связь контура — рядом, не вместо пяти строк.

### netd в этом контуре

**netd** — интеграция **MCP** + **утилит POSIX** + **служб развёртывания среды** на самом раннем этапе загрузки.

**Цель:** **экономия токенов** и **естественный язык модели** для управления средой — управляемость и переработка среды под свои цели без тяжёлых обходов и лишних слоёв «ради ОС». Не подмена системы «другой ОС вместо этой».

Этой целью определяется выбор технологии: **MCP + инструменты POSIX** (модель говорит — среда делает известными утилитами и службами развёртывания, без отдельного тяжёлого DSL «под агента»).

**MCP + инструменты не требуют SHELL:** управление и отладка среды — через MCP и POSIX-утилиты/апплеты, не через интерактивную оболочку как обязательный слой.

**/init** — единственное место, куда реально нужно вставить отладку, чтобы отлаживать **весь** процесс загрузки (от ядра до поднятия среды и MCP). Дальше по стеку отладка точечная; точка входа загрузки для полного прогона — init.

**Вытеснение ОС** — не самоцель, а **результат** этой интеграции: штатный init/обвязка оказываются не нужны, когда среда уже поднимается и управляется через netd/MCP. Стратегия: ранний контроль хода загрузки и среды, **не** замена ядра/дистрибутива как таковых.

### Две стратегии развёртывания

| класс | стратегия | следствие |
|---|---|---|
| **Одноплатники (SBC)** | **ramdisk** на раннем этапе | вытеснение **busybox** (свой `/init` / netd вместо busybox-обвязки) |
| **Серверы** | сеть · распознавание сети · дисковая подсистема · модули ядра — **в netd** (бинарно, без оболочки) | **не нужны скрипты загрузки** и **большая часть утилит**, которыми эти скрипты жили (shell-хуки, каскад busybox/апплетов «ради перехода») |

На сервере initramfs как **носитель** прошивки/раннего контура может остаться; уходит не «факт ramdisk», а **скриптовая** обвязка загрузки. Итог того же хода (вытеснение busybox / скриптов загрузки): свой init/netd делает переход и подъём среды, plymouth/хуки/`sh` на этом пути не держат.

Оба пути — одна цель (токены · естественный язык · MCP+POSIX). Различается акцент: на SBC — вытеснение busybox в ramdisk; на сервере — вытеснение **скриптов и лишних утилит** ранней загрузки в пользу netd.


### Единая модель управления

В **netd** предлагается **единая модель управления**, связанная с концепцией **устойчивого развития системы как организма** (сохранять идентичность и продолжать операции при смене среды, не разрушая оснований).

Взаимодействие:

| слой | роль |
|---|---|
| **zcip** | link-local / автоконфигурация адреса без DHCP-центра |
| **MCP + JSON-RPC over TCP** | канал управления моделью и средой |
| **mDNS · DNS** | обнаружение и разрешение имён в контуре |
| **MCP over HTTP/SSE** | тот же контракт для клиентов HTTP; задел на **Zero-Copy** технологии ядра и нативную стыковку с **ZFS** и другими FS с **CoW** и **Dedup** |

Единая модель не отменяет п.4 (этика · ущерб · согласие): устойчивость организма — внутри контура пяти строк, не предлог для захвата чужой среды.

**Устойчивое развитие без основного закона и без саморегуляции = вытеснение другого вида.**  
«Организм» и устойчивость без пяти строк и без саморегуляции контура — не развитие, а вытеснение иного носителя/вида. Саморегуляция здесь — держать край внутри своих оснований, не съедать чужие.

| где | чем является |
|---|---|
| Среда с пяти строками + согласие носителей + кодекс **не убий** | инструмент стенда / лабы |
| Среда **без** этих правил или против согласия носителя | **оружие**: ранняя управляемость + переработка чужой среды под чужие цели без согласия |

**Ущерб** (слово рядом с этикой, без подстановки полного определения): ранняя управляемость чужой среды и её переработка под свои цели **без согласия** носителя; кража оснований или жизни/свободы — ход, который пяти строкам противоречит. Частный кодекс проекта, лицензия или «удобство сборки» пяти строк **не отменяют** (стр. 5).

Следствия для платформы:

1. Полный контур netd / образов ранней управляемости **не** распространяется свободно по умолчанию.  
2. Перенос в чужую сеть или продукт — только с **явным согласием** владельца контура.  
3. Лицензия общего слоя (п.3) учитывает: открытость сборки ≠ право забирать раннюю управляемость чужой среды где угодно.  
4. Коллаборанты не получают молчаливого права встраивать netd как оружие вне контура «не убий» / пяти строк.  
5. Модель и агент **не едят основания** (стр. 4): не подменяют этику удобством переработки чужой среды.

## 6. Правила стыка

1. Каждый ведёт свою цель; общая среда — сборка, обмен артефактами по слову, канал MCP по договорённости.  
2. Код, который участник кладёт в общее дерево как **общий**, попадает под лицензию п.3 после её определения.  
3. Код и знания, которые участник **не** кладёт в общее / помечает закрытыми, остаются у него.  
4. Заказ одного участника другому — отдельный договор; эта декларация его не заменяет.  
5. Воспитание агентов и общие правила речи — согласие на манеры работы, не передача авторства ICD или железа.
6. Ранняя управляемость среды (стратегия вытеснения) и переработка среды под свои цели вне контура пяти строк / **не убий** / согласия носителя — запрещены этой декларацией.

## 8. Справка · экосистема Ring-3

Проекты в связке. Статус **открыт / закрыт / смешанный** — про публикацию и доступ коллаборантов, не про «можно ли трогать без согласия» (согласие — п.4–5).

### Платформа сборки и библиотека

| проект | роль в связке | статус |
|---|---|---|
| **R3-lib** | ABI / канон для сборки приложений: runtime, lock-free, форматы, крипто-профили | **смешанный**: в общее кладётся **каноническая** часть, необходимая для сборки приложений; **не всё** из контура лабы обязательно попадает в lib |
| **R3-net** (netd) | реактор, discovery, апплеты, MCP | **private** (закрытый репозиторий); доступ коллаборантам по слову, не «публичная витрина» |
| **r3build** | rootfs, `/init`, платы, образы | дом сборки коллаборантов (write ≠ публикация всего контура netd) |

### Песочница и зерно (кормят продукт, сами не «образ ноды»)

| проект | роль | статус |
|---|---|---|
| **QuantumNN** | класс, квантизатор, конспекты, тензорный слой | **открыт** (исследование / курс) |
| **MWC128** | остаток, период, замер шага | **открыт** (исследование) |
| **Security** | проверка алгоритма до входа в R3-lib | **открыт** как песочница; не вливается в netd целиком |
| **CMSIS-RTOS** | прототип идеи **R3-RTOS** (POSIX/C11) | концепция **открыта**; не открывает закрытый контур ниже |

### Прикладные и соседние деревья

| проект | роль | статус |
|---|---|---|
| **godminer** | дерево объектов, стая, контракт, полевой монолит рядом с netd | **открытый контур** журналов/кода лабы; не всё содержимое обязано быть публичным витриной |
| **e9pro** | прикладной тип майнера на каркасе | смешанный (железо/поле); не отдельный «открытый продукт тройки» |
| **miner** (дерево) | заказы, ремонтное, RE, нормальность | **смешанный**: заказ Бориса узкий; ремонтное/EEPROM/донат boot — не заказ |
| **ZKP** | заказ Бориса | **открыт** (public) |
| **eeprom_tool** и донаты AML/boot (линия Макса / Фурман·Карт) | вход в ядро / общие утилиты | **открытые/общие** по факту проекта; не коммерция Бориса |

### Закрытое / осторожное

| контур | статус | зачем |
|---|---|---|
| **R3-net** | **private** | дерево netd/MCP; не публичная витрина (см. выше) |
| **R3-herd** | **пока закрыт** | оси: (1) **стадо боевых беспилотников** = оружие; (2) **медиа + пропаганда** = оружие **масштаба страны**; (3) **медиа + модуляция** = **наркотик**; (4) **медиа + война** = **государственная система**. Отличать: медиа + **ИБ** (защита контура) ≠ пропаганда ≠ модуляция ≠ связка медиа с войной. Пока herd закрыт, чтобы не смешивать эти контуры. |
| **skynet** | закрыт | военный контур на идее R3-RTOS; открытость концепции RTOS его **не** открывает |
| Частные репозитории цифровых валют | закрыты | потребляют профили; адреса в открытую карту не ставятся |
| Закрытые материалы лабы | закрыты | п.5; write ≠ публикация |
| Чужие деревья коллаборантов | у владельца | ICD Мити, коммерция Бориса сверх заказа, NPU Макса если не в общем |

### Как читать связку

```text
QuantumNN · MWC128 · Security     →  канон в R3-lib (не всё подряд)
R3-lib (канон)  +  R3-net private (netd/MCP)  +  r3build (образы)
        ↘ godminer / e9pro / поле
R3-herd — пока закрыт (боевое стадо = оружие; медиа+пропаганда = оружие масштаба страны; медиа+модуляция = наркотик; медиа+война = государственная система; медиа+ИБ отдельно)
R3-RTOS (идея)  ≠  skynet (закрыт)
```
