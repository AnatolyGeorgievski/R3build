## Экосистема

Проекты в связке. Статус **открыт / закрыт / смешанный** — про публикацию и доступ коллаборантов, не про «можно ли трогать без согласия» (согласие — декларация §4–5).

### Платформа сборки и библиотека

| проект | роль в связке | статус |
|---|---|---|
| **R3-lib** | ABI / канон для сборки приложений: runtime, lock-free, форматы, крипто-профили | **смешанный**: в общее кладётся **каноническая** часть, необходимая для сборки приложений; **не всё** из контура лабы обязательно попадает в lib |
| **R3-net** (netd) | реактор, discovery, апплеты, MCP | **private** (закрытый репозиторий); доступ коллаборантам по слову, не «публичная витрина» |
| **r3build** | rootfs, `/init`, платы, образы | дом сборки коллаборантов (write ≠ публикация всего контура netd) |

### Песочница и зерно (кормят продукт, сами не «образ ноды»)

| проект | роль | статус |
|---|---|---|
| **QuantumNN** | класс, квантизатор, конспекты, тензорный слой | **открыт** (исследование / курс) |
| **MWC128** | остаток, период, замер шага | **открыт** (исследование) |
| **Security** | проверка алгоритма до входа в R3-lib | **открыт** как песочница; не вливается в netd целиком |
| **CMSIS-RTOS** | прототип идеи **R3-RTOS** (POSIX/C11) | концепция **открыта**; не открывает закрытый контур ниже |

### Прикладные и соседние деревья

| проект | роль | статус |
|---|---|---|
| **godminer** | дерево объектов, стая, контракт, полевой монолит рядом с netd | **открытый контур** журналов/кода лабы; не всё содержимое обязано быть публичным витриной |
| **e9pro** | прикладной тип майнера на каркасе | смешанный (железо/поле); не отдельный «открытый продукт тройки» |
| **miner** (дерево) | заказы, ремонтное, RE, нормальность | **смешанный**: заказ Бориса узкий; ремонтное/EEPROM/донат boot — не заказ |
| **ZKP** | заказ Бориса | **открыт** (public) |
| **eeprom_tool** и донаты AML/boot (линия Макса / Фурман·Карт) | вход в ядро / общие утилиты | **открытые/общие** по факту проекта; не коммерция Бориса |

### Закрытое / осторожное

| контур | статус | зачем |
|---|---|---|
| **R3-net** | **private** | дерево netd/MCP; не публичная витрина (см. выше) |
| **R3-herd** | **пока закрыт** | оси: (1) **стадо боевых беспилотников** = оружие; (2) **медиа + пропаганда** = оружие **масштаба страны**; (3) **медиа + модуляция** = **наркотик**; (4) **медиа + война** = **государственная система**. Отличать: медиа + **ИБ** (защита контура) ≠ пропаганда ≠ модуляция ≠ связка медиа с войной. Пока herd закрыт, чтобы не смешивать эти контуры. |
| **skynet** | закрыт | военный контур на идее R3-RTOS; открытость концепции RTOS его **не** открывает |
| Частные репозитории цифровых валют | закрыты | потребляют профили; адреса в открытую карту не ставятся |
| Закрытые материалы лабы | закрыты | п.5; write ≠ публикация |
| Чужие деревья коллаборантов | у владельца | ICD Мити, коммерция Бориса сверх заказа, NPU Макса если не в общем |

**Устойчивое развитие без основного закона и без саморегуляции = вытеснение другого вида** (декларация §4).

### Как читать связку

```text
QuantumNN · MWC128 · Security     →  канон в R3-lib (не всё подряд)
R3-lib (канон)  +  R3-net private (netd/MCP)  +  r3build (образы)
        ↘ godminer / e9pro / поле
R3-herd — пока закрыт (боевое стадо = оружие; медиа+пропаганда = оружие масштаба страны; медиа+модуляция = наркотик; медиа+война = государственная система; медиа+ИБ отдельно)
R3-RTOS (идея)  ≠  skynet (закрыт)
```
