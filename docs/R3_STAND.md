> Кухня и хроника хода — в журналах godminer. **Канон концепции стенда живёт здесь:** стенд — часть системы сборки и отладки софта Ring-3, не отдельный «умный дом ради умного дома».

## Зачем в r3build

Образы (`/init`, ramdisk, `board/`, TFTP/fastboot-подобный цикл) бессмысленны без **полки, на которой их гоняют**. Стенд = контур приёмки сборки: плата · сеть · консоль · кнопка питания · MCP.

| слой | где |
|---|---|
| норматив совместной работы | `docs/R3_DECLARATION.md` · `docs/R3_ECOSYSTEM.md` |
| **концепция стенда** | **этот файл** |
| железо слотов | `board/` (+ README «сейчас/позже») |
| ранний `/init` | `src/init/` |
| ход / ТЗ-черновик | godminer `log/` (не подменяет канон) |

## Три имени одного предмета

| имя | угол |
|---|---|
| **полка отладки софта** | много терминалов к платам; образы с host (TFTP / boot.img); не держать железо зря |
| **макет** | физика на столе до «красивого шкафа»; доказывает топологию |
| **умный дом / электрощит** | реле и сценарии вкл/выкл/reset; горизонт продукта из платы **коммутации** |

Это не три проекта. Продуктовый горизонт электрощита растёт из роли коммутации на макете.

## Модель цикла (как fastboot у Мити)

```text
SD / QSPI — тонкий stub загрузки (один раз)
     │
     ▼
host (arc2 / umbar) — меняющийся payload: kernel + dtb + ramdisk net_init|netd
     │  TFTP · dnsmasq · cdba/fastboot
     ▼
плата: zcip/link → MCP :8443 → gpio / дальше POSIX
```

Полный `dd` rootfs на SD каждый раз — **не** модель стенда.  
Свой SoC — не обязательный старт: сначала готовый SBC (`radxa` / `orange` / `rpi`), свой boot — когда контур жив.

## Макет · три разные платы

```text
полка-макет
  ├── DUT A          — отладка / netboot / UART
  ├── DUT B          — другой кремний
  └── коммутация     — мозг кнопок (MCP+gpio → I2C-реле / uhubctl 5V)
                         └── горизонт: умный электрощит
```

DUT и мозг кнопок **не** на одной плате. Одна из трёх — только коммутация.

## Инструмент кнопок

Уже есть: **MCP + gpio** (`netd`). Новый демон «как cdba» не пишем.  
cdba / umbar — референс поведения (список · консоль · power), не дерево для штопки с arc2.

Цепочка силы: MCP(+gpio) → I2C-реле → 12V/220V. Исключение: **PoE** (софт линка).

## Границы v0

**Входит:** ≥1 слот с путём tty или SSH; netboot-stub + payload с host; smoke MCP/gpio; карта слотов в `board/`.  
**Не входит:** flash-ферма; веб-витрина; авто-discover всего поля; чужой umbar как наш код.

Приёмка: видно плату и провод; с host — терминал или MCP; погасить/поднять через gpio/реле; вслух: «провода и кнопки, не сервер с GPU».

## Открытые места

Модель реле-платы · расклад I2C · число слотов первой полки · hold-таймаут — не заполнять здесь выдумкой. Слово [[george]].

## SSH на платы

На DUT **RSA достаточен**. ECC (ed25519/…) — зависит от сборки sshd/dropbear в образе; не предполагать.
