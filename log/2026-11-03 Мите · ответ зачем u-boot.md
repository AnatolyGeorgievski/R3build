## Текст в чат (коротко)

U-Boot взяли из твоего `build-u-boot-rb1.sh` — единственный явный рецепт mkbootimg + dtb рядом. Это обход, не цель.

На полке нам нужен тест **ядра**: Linux Image.gz/zImage + dtb → boot.img → cdba. U-Boot в образе — твой частный путь RB1 (capsule), для этого не нужен.

Канал проверили. Сейчас на rb1-1 через cdba: Linux + наш `/init` (net_init, stay в initramfs). U-Boot в этом образе нет.
